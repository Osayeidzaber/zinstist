# Jilaton Client

Jilaton Client is a Java/Fabric client in active development. The current build contains a lifecycle-aware module/settings system, persistent configuration with named profile storage, and a configurable HUD. Its searchable, scrollable ClickGUI uses a dark navy palette, category counts and custom icons, an enabled-only filter, compact/roomy module rows, expandable settings, module toggles, and Keybinds, Config Profiles, Theme Studio, and HUD Editor pages over a native blurred backdrop. Theme Studio supports five Jilaton palettes and an editable HSB accent whose choice persists across launches and profiles; the HUD uses the same accent. The HUD includes configurable watermark, active-module, FPS/ping, coordinate, and keystroke widgets; the keystroke display follows the user's current Minecraft movement and jump bindings. The HUD Editor currently supports dragging widgets and saving normalized positions in the main config and named profiles; resizing and per-widget color/opacity controls remain to be implemented. Registered modules are AntiBot, Friends, Teams, AimAssist, KillAura, Criticals, CrystalAura, Triggerbot, Velocity, WTap, AutoClicker, AutoTotem, AutoPot, AutoGapple, AutoArmor, Sprint, Parkour, NoSlow, Fullbright, Swing Animations, NoBob, and HUD. Criticals delays a qualifying ground attack, jumps, then replays it during the vanilla falling-critical window; range, wait duration, player-only targeting, and line of sight are configurable. Swing Animations adapts LiquidBounce's first-person swing transforms, with eleven selectable styles and a configurable scale; both settings persist and update live through the ClickGUI. WTap offers W-Tap and S-Tap modes, tap duration, a players-only filter, and a forward-input filter. W-Tap clears forward input for the configured tap period; S-Tap also sets backward input while preserving lateral movement and other controls. Sprint automation yields during the tap window. AutoGapple uses ordinary golden apples before enchanted ones, respects a health threshold and item cooldowns, and restores the prior hotbar slot after use when the player has not manually changed it. AutoArmor scores the complete worn loadout against a six-point hit, weighing armor, toughness, enchantments, knockback resistance, and remaining durability; it can skip Binding Curse gear and exposes upgrade, durability, and equip-delay settings. The user supplied Anubis 0.9.9.3 JAR was inspected only as a static reference; neither it nor the other supplied client JARs were executed or included in the build. Minecraft 1.21.11 has been launched through Loom's development profile, and the ClickGUI opened after the duplicate blur request was removed. No real account or multiplayer server was used. The Swing Animations mixin is build- and mapping-verified but has not been exercised in a live game.

Anubis source recovery is retained under `reference/` for attribution and investigation. It is not part of Jilaton's source set. The supplied JAR declares GPL-3.0-only; see `LICENSE` and `ATTRIBUTION.md`. Jilaton's new implementation does not copy recovered source or proprietary client assets.

The retained Anubis JAR and analysis artifacts remain outside the build source set. No untrusted JAR was executed.
