# Jilaton Client

Jilaton Client is a Java/Fabric client in active development. The current build contains a lifecycle-aware module/settings system, persistent configuration with named profile storage, and a configurable HUD. Its searchable, scrollable ClickGUI uses a dark navy palette, category counts and custom icons, an enabled-only filter, compact/roomy module rows, expandable settings, module toggles, and Keybinds, Config Profiles, Theme Studio, and HUD Editor pages over a native blurred backdrop. Theme Studio supports five Jilaton palettes and an editable HSB accent whose choice persists across launches and profiles; the HUD uses the same accent. The HUD includes configurable watermark, active-module, FPS/ping, coordinate, and keystroke widgets; the keystroke display follows the user's current Minecraft movement and jump bindings. The HUD Editor currently supports dragging widgets and saving normalized positions in the main config and named profiles; resizing and per-widget color/opacity controls remain to be implemented. The current modules are Sprint, Fullbright, AimAssist, WTap, AutoClicker, Triggerbot, AutoTotem, AutoArmor, AutoGapple, and HUD. WTap responds to Fabric's entity-attack callback, briefly releases sprint, then resumes it when forward sprinting remains requested; it has configurable release ticks and a players-only filter. AutoGapple uses ordinary golden apples before enchanted ones, respects a health threshold and item cooldowns, and restores the prior hotbar slot after use when the player has not manually changed it. The user supplied Anubis 0.9.9.3 JAR was inspected only as a static reference; neither it nor the other supplied client JARs were executed or included in the build. Minecraft 1.21.11 has been launched through Loom's development profile, and the ClickGUI opened after the duplicate blur request was removed. No real account or multiplayer server was used. The compact sidebar revision, HUD Editor, and WTap behavior still need in-game verification.

Anubis source recovery is retained under `reference/` for attribution and investigation. It is not part of Jilaton's source set. The supplied JAR declares GPL-3.0-only; see `LICENSE` and `ATTRIBUTION.md`. Jilaton's new implementation does not copy recovered source or proprietary client assets.

The retained Anubis JAR and analysis artifacts remain outside the build source set. No untrusted JAR was executed.
