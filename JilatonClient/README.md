# Jilaton Client

Jilaton is a Java 21/Fabric client for Minecraft 1.21.11, in active development. Its title screen now uses an original dark layout, theme accent, animated backdrop, and a vector J mark. Singleplayer, Multiplayer, Options, Client UI, and Quit controls use Minecraft widgets and preserve the menu as their parent where appropriate. The ClickGUI provides searchable modules, expandable settings, keybinds, config profiles, theme editing, and a HUD editor. The configurable HUD includes watermark, active modules, FPS/ping, coordinates, and keystrokes; its editor supports dragging and saved positions, with saved per-widget scale, panel opacity, accent, alignment and visibility controls.

The module manager currently registers 52 modules across combat, movement, render, and client features. KillAura, AutoClicker, and AutoShoot expose eight click pacing profiles through a shared rolling 20-tick scheduler; AutoShoot honors item cooldowns and limits projectile bursts to two attempts per client tick. AutoShoot targets visible filtered players and supports eggs/snowballs, optional generic held-item use, direct or ballistic aim, movement lead, and hotbar selection. ElytraTarget follows a visible filtered player during Elytra flight, predicts target movement, nudges upward before a predicted collision, and can use firework rockets. AutoLeave can gracefully disconnect from a multiplayer server when health remains below a configured threshold, while respecting creative/singleplayer and death-protection cases. AutoArmor can prioritize durable replacements using a configurable durability threshold. Criticals offers Jump and natural Wait modes with a bounded queued-attack replay. AimAssist supports factor-based smoothing and independent horizontal/vertical rotation settings; AutoClicker has Enemy/Entity/Block/Any attack objectives, saved weapon-category filters, a 300 ms break pause, and optional post-use delay. Velocity adds an optional bounded ray gate that applies Strafe only while the visible camera is pointed at a valid nearby target. Flight adapts Creative flight speed, force-flight, velocity limiting, and the generic open-air heartbeat. Teams filters scoreboard allies, matching explicit name colors, and same-slot dyed armor colors. Module implementation depth varies; the implementation inventory tracks source coverage, dependencies, testing, and unported modes. Middle-clicking a targeted player toggles saved friend status; friends are excluded from combat targeting and shown with a blue overhead hat. Settings and profiles persist locally. The title screen, friend hat, KillAura schedule/combat behavior, Teams name/armor-color matching, AimAssist live rotation, AutoClicker weapon/timing/input behavior, AutoShoot, ElytraTarget, AutoLeave, AutoArmor inventory swapping, Velocity OnlyFacing live rotation, Flight behavior, and several movement/combat behaviors have not yet been verified in-game. The latest full build passed 259 automated tests with zero failures, errors, or skips; this is not evidence of live client behavior.

Anubis source recovery is retained locally under `reference/` for attribution and investigation and is excluded from Git. It is not part of Jilaton's source set. The supplied JAR declares GPL-3.0-only; see `LICENSE` and `ATTRIBUTION.md`. Jilaton's new implementation does not copy recovered source or proprietary client assets.

The retained Anubis JAR and analysis artifacts remain outside the build source set. No untrusted JAR was executed.

Current engineering checkpoint, exact runtime checks and remaining work: [development/CHECKPOINT.md](development/CHECKPOINT.md). Machine-readable inventory: [development/integration-manifest.json](development/integration-manifest.json).

Zoom defaults to holding C; its HUD/ClickGUI settings support toggle mode, scroll zoom and mouse sensitivity scaling. `/jilaton gui` and `/jilaton hud` open the native editors; `/jilaton toggle <module_id>` changes and saves a module state. The HUD editor uses TAB for selection, brackets for scale, minus/equal for panel opacity, C for color, A for alignment, H for visibility, R for reset and M for reduced motion.
