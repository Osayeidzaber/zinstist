# Jilaton Client

Jilaton Client is a Java/Fabric client in active development. The current build contains a lifecycle-aware module/settings system, persistent configuration, and a searchable in-game control screen, with Sprint, Fullbright, AimAssist, AutoClicker, Triggerbot, and AutoTotem modules. The user supplied Anubis 0.9.9.3 JAR was inspected only as a static reference; neither it nor the other supplied client JARs were executed or included in the build. The JAR has not yet been run in Minecraft.

Anubis source recovery is retained under `reference/` for attribution and investigation. It is not part of Jilaton's source set. The supplied JAR declares GPL-3.0-only; see `LICENSE` and `ATTRIBUTION.md`. Jilaton's new implementation does not copy recovered source or proprietary client assets.

The retained Anubis JAR and analysis artifacts remain outside the build source set. No untrusted JAR was executed.
