# Jilaton Client

Jilaton is a Java 21/Fabric client for Minecraft 1.21.11, in active development. Its title screen now uses an original dark layout, theme accent, animated backdrop, and a vector J mark. Singleplayer, Multiplayer, Options, Client UI, and Quit controls use Minecraft widgets and preserve the menu as their parent where appropriate. The ClickGUI provides searchable modules, expandable settings, keybinds, config profiles, theme editing, and a HUD editor. The configurable HUD includes watermark, active modules, FPS/ping, coordinates, and keystrokes; its editor supports dragging and saved positions, while resizing and per-widget color/opacity controls remain open work.

The module manager currently registers 47 modules across combat, movement, render, and client features. AutoShoot targets visible filtered players and supports eggs/snowballs, optional generic held-item use, direct or ballistic aim, movement lead, hotbar selection, and configurable throw timing. ElytraTarget follows a visible filtered player during Elytra flight, predicts target movement, nudges upward before a predicted collision, and can use firework rockets. AutoLeave can gracefully disconnect from a multiplayer server when health remains below a configured threshold, while respecting creative/singleplayer and death-protection cases. AutoArmor can prioritize durable replacements using a configurable durability threshold. Criticals offers Jump and natural Wait modes with a bounded queued-attack replay. AimAssist supports factor-based smoothing and independent horizontal/vertical rotation settings; AutoClicker has a saved weapon-category filter, a 300 ms break pause, and optional post-use delay. Module implementation depth varies; the implementation inventory tracks source coverage, dependencies, testing, and unported modes. Middle-clicking a targeted player toggles saved friend status; friends are excluded from combat targeting and shown with a blue overhead hat. Settings and profiles persist locally. The title screen, friend hat, AimAssist live rotation, AutoClicker weapon/timing/input behavior, AutoShoot, ElytraTarget, AutoLeave, AutoArmor inventory swapping, and several movement/combat behaviors have not yet been verified in-game. The latest clean build passed 198 automated tests; this is not evidence of live client behavior.

Anubis source recovery is retained under `reference/` for attribution and investigation. It is not part of Jilaton's source set. The supplied JAR declares GPL-3.0-only; see `LICENSE` and `ATTRIBUTION.md`. Jilaton's new implementation does not copy recovered source or proprietary client assets.

The retained Anubis JAR and analysis artifacts remain outside the build source set. No untrusted JAR was executed.
